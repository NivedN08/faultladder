# Status

- Phase: 4 (baselines and gates) done on the branch `phase-4-baselines`;
  waits on the owner's review.
- Last gate: Phase 4 passed. All six validity gates pass on ladder v1
  (`results/gate.md`, regenerate with `uv run python -m faultladder.gate`).
- Leaderboard: `results/leaderboard.md`, generated by
  `uv run python -m faultladder.leaderboard` from the `ladder.json` files.
  Four PPO baselines, training seeds 0 to 4, 1,320 iterations each, 4,096
  episodes per cell.
- Ladder: frozen as `src/faultladder/ladder_v1.json`. Do not change a level;
  a new ladder needs a new version.
- Baselines (`src/faultladder/tasks.py`): no randomisation, default (mjlab's
  task unchanged), wide (motor fault, payload, latency and push up to level 3;
  friction already reaches level 3 in the default task), privileged (wide plus
  16 fault parameters in the observation, scored on a matching eval task).
- Changes from the plan in Phase 4:
  - Calibration round 2 of 3: latency 1 to 5 control steps became 0.5, 1, 2,
    3, 5 and push 0.5 to 2.5 m/s became 0.5 to 1.5 m/s, because both axes
    fell from near 1 to near 0 in one level. Latency may be half a control
    step (two physics steps).
  - The seed spread in G3 is the larger of the two baselines' standard
    deviations across seeds. G5 uses the mean across seeds.
  - Jobs ask for an L4 and fall back to an A10; every Phase 4 job got an A10.
- Changes from the plan in Phase 3, still in force: one command per episode
  with a commanded speed of at least 0.4 m/s; the eval task removes the base
  task's own randomisation; calibration round 1 changed payload to 0.12 to 0.6.
- Known weak spots of ladder v1:
  - Latency is still steep for the default policy (level 2 about 0.77,
    level 3 about 0.01); it is graded for the other three baselines.
  - Payload and latency are close to solved by the wide policy (axis scores
    above 0.9), so they leave little room above it.
  - Wide and privileged score alike on the motor axes at levels 4 and 5;
    knowing the fault does not help there.
- `results/cpu_transfer/ladder.json` is from ladder v0. It covers only the
  nominal cell, which no calibration round changed.
- Spend: Phase 4 about $15.39 of the $50 cap; project total about $18.75

  start-up; the Modal dashboard has the real figure).
- Modal account: usage limit $180, spend limit $0, so only credits are used.
